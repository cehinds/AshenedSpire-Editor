# Book Atelier

Open **Project tools → Book Atelier**. The approved painted book art has three bindings and eleven independent metal emblems, including the feat laurel. Leather color reaches the front, spine, back and ribbon; brass fittings and parchment keep their painted colors. Metal tint, polished/aged/seal finish and optional tooling are independent. The original approved ten-book palette is preserved.

Edits are stored in the project's optional `bookArt` map, with normal autosave, Undo/Redo, whole-project import/export and cross-tab conflict protection. Import recipes accepts either the game's plain map or `{ "recipes": { ... } }`, validates the entire file before applying, and refuses unknown layer selections and malformed colors. Export JSON exchanges recipes with the game preview; Export game module produces `src/content/bookArtPresets.js`.

For a local game checkout, expand **Save artwork to game checkout**, find connected local checkouts, and choose the game. Load imports its existing recipes into the draft. Review reads the current module, parses the exported object without evaluating JavaScript, and displays before/after source. Save replaces only the `BOOK_ART_PRESETS` object literal, preserves comments and other exports, and retains checkout records omitted from an older imported recipe file. Changes to the draft or selected checkout invalidate the review; the existing host file API rejects stale revisions and enforces its session, CSRF, path and branch protections. Saving does not commit, push or change gameplay rules. Static Pages builds provide authoring and exports only.

Artwork is vendored under `public/assets/books` from the approved AshenSpire painted-v2 kit. `provenance.json` retains generation references; the runtime renderer is adapted only to resolve the editor's bundled URLs. Consolidated Pages embeds the assets and uses data URLs so SVG images remain visible offline.

Validation: `node --test tests/book-art.test.mjs` covers the palette, all WebP layers, JSON validation, restricted source parsing and source preservation. `scripts/book-atelier-browser.mjs` exercises actual controls, export/import, persistence, desktop/mobile layout and mocked checkout API stale-review/revision behavior. Existing host integration tests cover the real file API's revision and security enforcement. Set `BOOK_EDITOR_STATIC=1` when running the browser probe against a consolidated public build.
